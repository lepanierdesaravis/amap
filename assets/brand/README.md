## Typographies
- Site actuel : Raleway, DIN Next Light, Nimbus Sans condensé, Mr De Haviland (manuscrite).
- Proposition : **Raleway** pour les titres (continuité), **Lato** pour le texte (très lisible sur mobile). Une manuscrite légère (par exemple *Caveat*) peut servir pour quelques accroches, en rappel du logo. Toutes ces polices sont gratuites (Google Fonts) et peuvent être hébergées sur notre serveur, sans appel à Google, ce qui est plus respectueux du RGPD.
